📐 Computer Graphics Algorithm: Bresenham Line Drawing Algorithm
Pixel-accurate line rasterization on HTML5 Canvas using pure integer arithmetic and error terms.
College Viva Assignment Module
📘 Viva Explanation & Working Principle:
• Why Bresenham? Standard line formulas use floating-point division (y = m*x + c), which is computationally expensive on raster hardware. Bresenham replaces floating point math with pure integer additions and bit-shifts.
• Decision Parameter (D): At step (x, y), the next pixel can either be East (x+1, y) or North-East (x+1, y+1). The algorithm computes D = 2*dy - dx. If D ≤ 0, select East and increment D += 2*dy. If D > 0, select North-East and increment D += 2*(dy - dx).
• Code Location: Located in separate, well-commented file at src/main/resources/static/js/bresenham.js.
